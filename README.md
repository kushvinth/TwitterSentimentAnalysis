# Twitter Sentiment Analysis Dashboard

A Flask-powered website for this repository's Twitter sentiment backend.

## Features

- Analyze tweets for any keyword in real time
- Sentiment breakdown (positive / neutral / negative)
- Average polarity and subjectivity metrics
- Dashboard UI with tweet cards and a sentiment chart
- CSV export is still generated by the existing analyzer

## Setup

1. Copy environment variables:
   ```bash
   cp .env.example .env
   ```
2. Fill your Twitter credentials in `.env`.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Run the website

```bash
python app.py
```

Then open `http://127.0.0.1:5000` in your browser.
